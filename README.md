# Fran Santillana · Reformas & proyectos (web de muestra)

Web de muestra preparada por NOCODYA para Fran Santillana, alicatador y reformista en Elche y alrededores. No es todavía la web oficial.

- Fotos y vídeo: de sus publicaciones de Instagram (@fs.reformas_) y de su ficha de Google, ampliadas y limpiadas de rótulos.
- Reseñas: las de su ficha de Google (5,0 con 11 reseñas).
- Logo: redibujado a partir del suyo.
- El formulario solo abre WhatsApp con el mensaje escrito; no guarda datos.
- Por confirmar con el cliente: razón social, NIF, dirección, correo, dominio y textos legales.
